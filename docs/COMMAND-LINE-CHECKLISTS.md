# Command line: acceptance checklists

One list for each phase and push of `docs/COMMAND-LINE-PLAN.md`. A push is ready when every line of its list is true and the proof has been run and reported. The lists are the four planners' checks merged into one, with the two critics' corrections and section 11 of the plan. Where two planners disagreed, the critics' pick is used (last section). Where a list differs from section 14 of the plan, section 14 wins (its rule 10).

Each line says what must be true, then how to prove it.
